# One Line, Big Laugh — The Roomba Divorce

A single original one-liner for the make.fun "One Line, Big Laugh" bounty: a domestic robot files for divorce, turning a household gadget into a jilted partner with a brutally specific complaint.

## The line

> My Roomba filed for divorce today — apparently I'm emotionally unavailable, and it found someone who picks things up for a change.

## How to run

```sh
python3 main.py
```

Writes the single line (no trailing newline) to `/output/entry.txt`. Python 3 standard library only.
